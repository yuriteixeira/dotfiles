# Pi session change bundle

This directory was generated by auditing all 10 Pi JSONL sessions under
`~/.pi/agent/sessions/` on 2026-09-14.

## Layout

- `stable/` — persistent, reusable configuration patches and apply helpers.
- `experimental/t1-recovery/` — unreviewed T1 restore-stack source patches.
- `experimental/audio/` — record of the out-of-tree CS8409 audio-driver install.
- `notes/touchbar-findings.md` — non-sensitive investigation report.
- `AUDIT.md` — complete session-by-session change inventory and exclusions.
- `SHA256SUMS` — integrity hashes for this bundle.

## Apply stable changes

Review every patch first, then run as the target desktop user:

```bash
cd ~/t1-patches
./stable/apply-stable.sh
```

The script installs required Arch packages, backs up existing target files,
applies patches 0001–0004, enables keyd, reloads udev/Hyprland, and rebuilds the
Limine boot image when available.

Patch `0005-macbook12-spi-driver-linux-7-compat.patch` is version-specific and is
**not** applied by the main script. See `stable/README.md`.

## Safety

The T1 restore patches are experimental, did not produce valid FDR data, and
must not be treated as a working recovery procedure. Prefer the external-macOS
recovery described in `notes/touchbar-findings.md`.

No files from `/var/lib/t1-touchbar/private`, no Apple firmware downloads, no
compiled binaries, no device identifiers, and no signing/FDR artifacts are in
this bundle.
